# Участие в разработке

Спасибо за помощь проекту. Основная цель ветки `6.3.4` — предсказуемый запуск
Majestic Launcher 6.3.4 с GTA V Legacy через Proton.

Перед работой прочитайте [AGENTS.md](AGENTS.md): там зафиксированы требования к
безопасности, патчеру и проверке новых версий лаунчера.

## Рабочий процесс

1. Создайте fork репозитория.
2. Создайте отдельную ветку для изменения.
3. Не добавляйте бинарники Majestic, игровые файлы или распакованный `app.asar`.
4. Добавьте или обновите синтетические тесты.
5. Выполните проверки.
6. Откройте Pull Request с описанием проверенной конфигурации и ограничений.

## Обязательные проверки

```bash
bash -n install-and-run-majestic-proton.sh
python3 -m compileall -q majestic_linux
python3 -m unittest discover -s tests -v
git diff --check
```

Если меняется патч лаунчера, дополнительно проверьте его на изолированной копии
официального установщика:

- первый запуск изменяет ожидаемые файлы;
- все маркеры присутствуют ровно один раз;
- `node --check` принимает изменённые JavaScript-файлы;
- второй запуск возвращает `changed=False`;
- оригинальный `app.asar.bak` сохранён без изменений.

## Требования к изменениям

- Не привязывайте код или примеры к конкретному имени пользователя, домашней
  директории, модели GPU или расположению Steam.
- Не добавляйте молчаливые сетевые загрузки.
- Официальный CDN Majestic можно использовать только после явного выбора
  пользователя.
- При отсутствии ожидаемого JS-якоря патчер должен завершаться ошибкой.
- Новые необязательные интеграции не должны включаться по умолчанию.
- Деструктивные операции должны показывать точные цели и требовать подтверждение.

## Pull Request

В описании укажите:

```text
Что изменено:
Зачем:
Версия Majestic Launcher:
Дистрибутив и версия Proton:
Какие проверки выполнены:
Что не проверено:
Известные ограничения:
```

Изменение поддержки версии лаунчера должно одновременно обновлять README,
CHANGELOG, тесты и метаданные версии.
