# История изменений

Здесь перечисляются заметные изменения проекта.

## [1.4.2] — 2026-10-29

### Исправлено

- AppImage восстанавливает системный `LD_LIBRARY_PATH` перед запуском Proton,
  `protontricks`, `kde-open` и других внешних программ. Это предотвращает
  загрузку библиотек OpenSSL из временного каталога PyInstaller (`/tmp/_MEI*`)
  системными утилитами.
- Добавлены регрессионные тесты для окружения PyInstaller с исходным
  `LD_LIBRARY_PATH` и без него.

## [1.4.1] — 2026-10-28

### Добавлено

- Совместимость с минифицированной структурой выбора GTA и updater gate в
  Majestic Launcher 6.3.4.
- Интерактивная настройка официального установщика через shell-скрипт.
- Явные неинтерактивные режимы `setup --download` и `setup --installer`.
- Синтетические регрессионные тесты патча Launcher 6.3.4 и идемпотентности.
- Тесты конфигурационных значений с пробелами.
- GitHub Actions для Python 3.11 и 3.13.
- Сборки `.deb`, `.rpm` и AppImage с публикацией артефактов для ветки `6.3.4`.
- Автоматическая публикация всех трёх форматов и `SHA256SUMS` в GitHub Release
  для тегов `v*`.

### Изменено

- Конфиг теперь сохраняет пути, названия GPU и другие значения с пробелами.
- Документация описывает проверенную версию лаунчера и безопасную процедуру
  обновления.
- Автоматическая загрузка возможна только по явному выбору пользователя и
  использует официальный CDN Majestic.
- Первый запуск готового пакета открывает настройку установщика, последующие
  запуски используют сохранённый пользовательский конфиг.

### Удалено

- Сторонний repacked-установщик по умолчанию.
- Discord RPC bridge и общий механизм sidecar-процессов.
- Автоматическая загрузка emoji-шрифта и установка шрифта в систему.
- Экспериментальная инъекция Steam Overlay.
- Автоматический repair GTA и Multiplayer из команды `patch`.

### Безопасность

- Необязательные сторонние бинарники больше не скачиваются и не запускаются.
- Патчер прекращает работу, если не находит ожидаемую структуру Launcher 6.3.4.
- Скачанный установщик проходит базовую проверку размера и PE-заголовка, после
  чего пользователю показывается SHA-256.

## [1.4.0] — 2026-08-19
